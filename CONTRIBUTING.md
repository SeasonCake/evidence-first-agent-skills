# Contributing

Keep changes narrow, project-neutral, and testable. Add a synthetic positive and negative
example when a rule changes. Do not add private incident logs, customer data, production
paths, credentials, or copied proprietary text. Run `python scripts/verify.py`.

Contributions use Developer Certificate of Origin 1.1 sign-off; no CLA is required.
Create signed-off commits with:

```text
git commit -s
```

The sign-off certifies the contribution under the terms in `DCO`.
