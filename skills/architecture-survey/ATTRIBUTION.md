# Attribution

Inspired by Matt Pocock's MIT-licensed `improve-codebase-architecture` skill. This rewrite
removes automatic interviewing, document mutation, external report hosting, and browser
actions; it adds bounded evidence, current-stage checks, consumer tracing, and a no-action
outcome. See the repository `UPSTREAM.md`.

Project origin: recurring BidKing maintenance showed that file size and churn alone do
not prove a refactor target. The public companion is
[`bidking-inference`](https://github.com/SeasonCake/bidking-inference).
